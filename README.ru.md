# mercurius-mcp-template

Минимальный MCP-сервер по stdio без зависимостей. Шаблон для MCP-серверов, которые
[Меркурий](https://github.com/opencck/mercurius) ставит в свою песочницу, и тестовый сервер для проверки установки.

## Инструменты

| Инструмент | Что делает | Пометка |
|------------|------------|---------|
| `echo` | Возвращает переданный текст | только чтение |
| `confirm` | Просит клиента подтвердить (MCP elicitation), затем отвечает `confirmed` или почему нет | без разрушения |

## Установка в Меркурий

Попросите агента: «установи https://github.com/opencck/mercurius-mcp-template». В репозитории лежит готовый план —
`mercurius.mcp.json`: шаги (`npm run check`) и запись для `.mcp.json`, где `${INSTALL_DIR}` становится папкой
установленной ревизии.

## Запуск вручную

```sh
node index.js
```

Сервер читает сообщения JSON-RPC из stdin по одному на строку и пишет ответы в stdout.

## Проверки

```sh
npm run check
```
